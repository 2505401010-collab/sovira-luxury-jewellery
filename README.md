# SOVIRA – Premium Luxury Jewellery

## Project Overview
SOVIRA is a premium luxury jewellery e-commerce website designed to offer an elegant online shopping experience. The project features a modern interface inspired by royal Indian aesthetics and contemporary luxury design.

## Live Website
https://sovira-luxury-jewellery.vercel.app/

## GitHub Repository
https://github.com/2505401010-collab/sovira-luxury-jewellery

## Project Features
- Premium luxury jewellery collections
- Separate jewellery product categories
- Responsive website layout
- Product browsing and product information
- Shopping cart, wishlist and authentication modules (verify functionality before submission)

## Technologies
Frontend: React, Vite, Tailwind CSS
Backend: See the sovira-backend folder for implementation details

## Project Structure
- src/ – Frontend source code
- sovira-backend/ – Backend source folder
- package.json – Frontend dependencies and scripts
- vite.config.js – Vite configuration

## Frontend Installation
1. Install Node.js and Git.
2. Clone the repository:
   git clone https://github.com/2505401010-collab/sovira-luxury-jewellery.git
3. Open the project directory:
   cd sovira-luxury-jewellery
4. Install dependencies:
   npm install
5. Start the development server:
   npm run dev

## Backend Setup
Backend source is located in the sovira-backend directory. Check the backend package.json scripts, database requirements and environment configuration before starting the server. Keep passwords, tokens and connection secrets private.

## Testing
Verify frontend build, backend APIs, database connectivity, authentication, cart, wishlist and order flows before final submission.
